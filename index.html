Organiza, Clona y Respalda tus Archivos en Linux

Memexicanisimos Files es la herramienta definitiva con asistente de 5 pasos para mantener tus directorios impecables, crear copias de seguridad incrementales y revertir cambios sin riesgo.

Para Linux (x86_64) – Solo descarga, descomprime y ejecuta sin necesidad de instalar dependencias:

Descargar .tar.gz (Linux x86_64) Descargar .zip (Linux)

Para usuarios en Windows o macOS, clona el repositorio y ejecuta el script automático de compilación (build_windows.bat o ./build_unix.sh).

Potencia y Simplicidad en 5 Pasos

Diseñado especialmente para resolver problemas comunes de almacenamiento en la comunidad Linux.

Análisis Inteligente de Destino

Detecta automáticamente la estructura de carpetas existente (por fecha, extensión o letra) para evitar carpetas duplicadas.

Sistema Undo con Registros JSONL

Revierte cualquier movimiento o copia fácilmente. Incluye modo simulación (Dry-Run) e historial de operaciones.

Renombrado con Metadatos de Audio

Usa placeholders inteligentes como {artista}, {album}, {titulo}, {ano} e incluye opción para limpiar metadatos sensibles.

Clonación Incremental y Discos

Realiza backups incrementales de carpetas personales y clonación de discos a nivel de bloque con ddrescue y verificación de checksum MD5.

Importador Multimedia

Conecta tu teléfono Android (MTP), cámara fotográfica (PTP) o pendrive y transfiere tus archivos organizadamente.

Estilo Pastel & Perfiles

Interfaz moderna con paleta de colores suaves Tkinter y sistema de perfiles para guardar configuraciones frecuentes.

Capturas de Pantalla

Conoce la interfaz gráfica clara y moderna de Memexicanisimos Files.

# 2. Ejecutar el script según tu Sistema Operativo:

# En Linux / macOS:
